## 二、关卡点子池（挑一个就是一张 C3 卡）

- **探索类**：迷宫里找钥匙、跳平台收集星星、挖矿找宝石、找出藏起来的小动物
- **答题类**：谜语（已做）、常识（已做）、拼音、古诗接龙、口算闯关、英语单词
- **收集类**：宝箱（已做）、捡水果、抓小动物
- **操作类**：打地鼠、躲滚石、按颜色踩方块、追小羊、跳跳乐（广场已有雏形）
- **战斗类**：圆形擂台缩圈混战（已做）、擂台守关、打 boss、看谁先把对手打下去
- **学习类**：汉字（已做）、田字格描红、看图识物、数数

## 三、技术债 / 隐患（有空就清）

| 项 | 现状 | 建议 |
| --- | --- | --- |
| `legacy/` 旧代码 | 不加载、不参考 | 确认没人回看后删掉（要用户点头） |
| 验证脚本依赖 `playwright-cli` | 需要本机有 Chrome | 没 Playwright 时至少跑 `scripts/check.sh` + 手工过一遍 |
| 后台标签页 rAF 节流 | 时间类玩法没法用 `sleep` 测 | 统一用「页面内手动步进」写法（见 `scripts/test-arena.sh`） |
| 擂台平衡 | 站桩会被推下台；人机互殴 3~4 分钟能打掉一半 | 每次改数值都跑 `scripts/test-arena.sh` 看节奏 |
| 存档没有备份 | 只在本机 localStorage | 导出 JSON 备份 / 云端同步 |
