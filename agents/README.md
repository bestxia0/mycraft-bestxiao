# agents/ · 角色提示词（多 Agent 并行用）

> 用法：**开一个新会话** → 把对应角色文件**整段贴进第一条消息** → 再贴任务卡号。
> 规则的正式定义在 `AGENTS.md` 第 3 节；这里是「开工时贴给 AI 的那段话」。

## 二、怎么起一个并行会话（推荐流程）

```text
【第一条消息】把 agents/30-level-dev.md 整段贴上
【第二条消息】
我是 C3。先读 AGENTS.md 第 1、2、3 节，再读 program/BOARD.md 和
program/tasks/TC-0003-mole-garden.md，然后按 TASK 段开工。
只动「允许改的文件」；干完写 RECEIPT 并把卡推到 review。
```

要点：
1. **一个会话一个角色一张卡**，别让一个会话同时干两件会互相冲突的事。
2. **物理隔离**：每人一个 git 分支 / worktree（见 `docs/COORDINATION.md` 第 4 节）。
3. 干完就**停手**，不要顺手改别人的文件 —— 想改就发 CHANGE 卡。
4. 看板状态只有 C0 能改；你只改自己那张卡的 `claimed` / `doing` / `review`。

## 三、家长一个人带 2~3 个 Agent 的实用编队

| 场景 | 建议编队 |
| --- | --- |
| 今天加 1 关 | C3（做关卡）+ C3 或 C5（顺手把验证脚本跑通） |
| 今天加 2 关 | 两个 C3 并行（一人一关，天然不冲突）+ C5 收口 |
| 今天加 1 关 + 1 个题库 | C3（关卡）+ C4（题库）+ C5；关卡里用 `Game.pickQuestions(n,{bank:'...'})` |
| 今天要一种全新玩法（引擎没有的零件） | C2 先做零件（出 CHANGE 回执）→ 再开 C3 关卡卡 |
