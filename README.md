# 方块小勇士 · 3D 卡通闯关小游戏

一个在浏览器里直接玩的**单机 3D 小游戏**，方块卡通风格（类似《我的世界》），
适合和小朋友一起玩：**没有联网、没有广告、没有账号，双击就能玩。**

它是为「**每天和小朋友一起加 1~2 个新关卡**」设计的：
所有关卡都在一张**开放式地图（方块小镇）**上，加一个新关卡只要复制一个文件夹 + 改一行清单。

**当前版本 v2.6.0** · 小镇广场 + 6 个关卡 · 谜语 65 道 / 常识 38 道 ·
**每关一首背景音乐**（能开能关）· 纯离线。

> 想加关卡 / 改代码？先看 **`AGENTS.md`**（项目结构 + 关卡 API 速查 + 验证流程 + 多 Agent 协作）。
> 想和小朋友一起口述设计新关卡？看 **`docs/工作流程.md`**（口述 → 设计卡 → 开发 → 试玩验收）
> 和 **`docs/关卡设计规范.md`**；设计卡放在 `levels/`。
> 想让多个 AI 同时帮你干活？看 **`agents/README.md`** 和 **`docs/COORDINATION.md`**。

## 一、怎么开始玩

**最简单：** 双击 `index.html`，用 Chrome / Edge / Safari 打开就能玩。

**如果双击打不开**（个别浏览器的本地文件限制），在「终端」里执行：

```bash
cd /Users/xiao/workspace/mycraft-bestxiao
zsh scripts/serve.sh            # 起本地服务器（默认 8777 端口）
```

然后浏览器打开 <http://127.0.0.1:8777/>

## 三、现在有什么玩

**🏠 方块小镇 · 广场（出生点）—— 可以随便玩的小镇**
所有关卡的出发点，也是一块**开放式的大空地**，不闯关的时候就在这儿玩。
广场上站着村长爷爷，头上的黄色箭头永远指向「现在该去的地方」；
广场尽头的传送门**自动按关卡数量排成一排**：通关一关，下一座门就会亮起来。

小镇上有 4 个自己玩的小地方，还有 8 枚闪闪的金币（每枚 +3 🪙）散在各处，路过就捡：
| 在哪 | 玩什么 |
| --- | --- |
| 东边 · 跳跳乐 | 三级石台一级一级往上跳，跳到顶上拿起 🏆 金杯（+30 🪙） |
| 西边 · 小迷宫 | 进去绕一圈，正中间有个宝箱（+25 🪙） |
| 南边 · 许愿池 | 走到池边投 10 🪙 许个愿，会有惊喜哦 |
| 南边 · 小花园 | 看看花，那块牌子会告诉你小镇有什么好玩的 |

**🌳 第 1 关 · 谜语森林** —— 猜谜语
森林里立着 6 座水晶石碑，按 `E` 读谜语、三选一。答对了石碑变绿（+10 🪙），
答错会给你提示，可以再想。**谜题只有文字，没有图案**，要靠脑子猜哦。
- **每轮 6 道题都是从题库里随机抽的**（题库目前 65 道，分 7 类：动物、花草树木、
  天气与自然、吃的喝的、生活用品、身体与穿着、汉字字谜），所以每次进来题目都不一样。
- **答过的题不会再重复出**：这一轮 6 道全答完 → 北边大门降下，走过去就通关；
  下次再进森林，石碑上会**自动换上 6 道新谜语**，可以接着猜。
- 不想离开森林？走到**中间的木牌**前面按 `E`，也能直接「🎲 换一批新谜语」。

**🎁 第 2 关 · 宝箱山谷** —— 找宝箱 + 答题 + 兑换更好的装备
山谷很大，散落 **20 个宝箱**（有的在石台上，要走台阶跳上去），
**要自己找**（这一关不显示头顶的黄色箭头），走到宝箱旁边按 `E`、**先答对一道常识题**才会打开，
把武器和装备全部收进背包（每箱 +5 🪙）。答错的题会告诉你「再想想」，还会给提示，可以一直试。
常识题从**生活 / 安全 / 自然 / 节日**四类里随机抽，**答过的不再重复出**。
然后去【铁匠铺】找铁匠大叔锻造：

| 配方 | 消耗 | 得到 |
| --- | --- | --- |
| ① | 任意 5 件普通装备 | 1 件稀有装备 |
| ② | 任意 3 件稀有装备 | 1 件史诗装备 |
| ③ | 任意 3 件史诗装备 | 1 件**传说 · 钻石勇者之剑** |

锻出传说之剑 = 通关，出口传送门亮起，手里的剑也会变成发光的钻石剑。
**炼出来的武器可以带去第 4 关打人**（背包里最好的那一件会自动变成手里的武器）。

**📚 第 3 关 · 汉字教室** —— 学习系统（示范关卡）
教室里摆着 5 张字卡桌，按 `E`「认字」：先看大字 + 拼音 + 意思 + 组词，
再做一道小测验。答对 +5 🪙，字卡变绿。5 个字全学会 = 通关。
学完以后**去找教室里的老师说话**，老师会**当场给你换一批新的汉字**，
可以接着学；下次再进教室也会自动换成没学过的新字，所以能一直学下去。

**⚔️ 第 4 关 · 圆形擂台** —— 缩圈混战
一座悬在空中的**大圆形擂台**，你和 **6 个**彩色小勇士（红 / 蓝 / 绿 / 黄 / 紫 / 橙）一起站在上面，
大家**互相打架** —— 人机之间也会互相打起来，不用你一个人对付所有人。
- 按 `F` 挥武器打人：**用的是第 2 关炼出来的武器**，武器越好，伤害和击退越强。
- **打中别人，自己也会被弹开**（双方都会退开一步），所以不会被黏住一直打；
  被打中的人会僵直 0.85 秒，可以**连着揍几拳**，手感更痛快。
- **血很厚**：自己 400 血、对手 300 血，人机互殴一下只掉 2 血 —— 所以一场能打到后面几轮缩圈。
- **每 3 分钟缩圈一次，一共缩 3 次**（52 → 40 → 29 → 20；擂台外面是空的，掉下去就输了）。
- 总时间 **9 分钟**，时间到了台上还有人站着的话，**再加 5 分钟**继续打（最多加 3 次）。
- 把 6 个对手全打下擂台 = 通关（+150 🪙）。一拳一拳把他们推到台边，**空手大约 6 拳能推下去一个**。
- 自己被打下去 / 掉下去 → 弹出面板，可以「回小镇」休息，也可以「马上再来一次」。

**🐎 第 5 关 · 沙漠逃亡** —— 骑马 + 2 分钟限时逃离
一大片沙漠，出生点旁边就是小马。走到小马跟前按 `F`（打它一下）就骑上去，
骑马用 `W A S D` 控制（按 `E` 下马），速度是走路的两倍。
目标是**在 2 分钟内**骑着马跑到西北角的绿洲石拱门逃出去。
- **头上的箭头只给「大概」方向**（会左右晃，不是精确指向），要靠自己找路。
- 路上有会游走的**小龙卷风**（被卷到会被吹起来，**骑着马会被卷下马**）、
  挡路的**仙人掌**（贴上去会被扎；按 `F` 可以打碎，碎掉路就通了）、
  会咬人的**小蛇**（按 `F` 能把它打飞）。
- **马会随机生成**：8 匹起步，玩着玩着还会有新马跑过来（最多 12 匹）。
- **2 分钟到了还没跑出去 → 自动传送回小镇**，不弹「失败」面板，想再玩就再进一次关。

**🎨 第 6 关 · 踩白大草原** —— 把绿色踩成白色 + 找正确的传送门
一整片**900 块绿地板**的大草原，你走过的地方就会变成白色。
**要在 6 分钟内把绿色全部踩成白色**，踩完还不算完 —— 草原外面围着一圈 **6 座传送门**，
只有 **1 座**能进入下一关，要自己试出来（每次进关都重新随机，走错只被弹开，不罚你）。
- **骑马踩得快得多**：走路一次只踩白脚下 **1 块**，骑上小马一次就踩白 **3 × 3 = 9 块**
  —— 这么大的草原，骑马才来得及（出生点旁边就有小马，按 `F` 骑上去）。
- 头顶箭头会一直指着**离你最近的那一块绿地**，不用满场乱找还剩哪里没踩。
- **踩不完 = 没通关**：时间到还没踩完 → 自动回小镇重来（和第 5 关同一个规矩）。
- 全踩白之后箭头会收起来（**不告诉你哪座门是对的**），只剩一句「外面那一圈只有 1 座是通往下一关的」。

## 四、存档

- **自动保存**：进度存在这台电脑的浏览器里（localStorage），关掉网页再打开接着玩。
- **多个小朋友**：开始界面 / 暂停菜单里可以「＋ 新档案」「换一个小朋友」，每人一份进度。
- **导出 / 导入存档**：开始界面有「💾 导出存档」和「📥 导入存档」，
  导出的 JSON 可以备份或换台电脑继续玩。
- **重新开始**：暂停菜单（`Esc`）→「重新开始这一局（清空进度）」，只清当前小朋友的进度。

> 所以不用联网、不用担心版权、拷到别的小朋友电脑上双击就能听。
> 想改曲子 / 给新关卡配一首 → 看 `docs/背景音乐.md`。

## 五、想加一个新关卡？（大约 5 分钟）

```bash
cd /Users/xiao/workspace/mycraft-bestxiao
cp -R src/levels/_TEMPLATE src/levels/mole-garden     # 1. 复制模板，文件夹名用英文
```

2. 打开 `src/levels/mole-garden/level.js`，把 `id` / `order` / `name` / `subtitle` / `icon`
   改成新关卡的，然后在 `build(ctx)` 里搭地图、写玩法（文件里有详细中文注释）。
3. 打开 `src/levels/index.js`，清单里**加一行**（记得给上一行补逗号）：

```js
  { id: 'mole-garden', files: ['levels/mole-garden/level.js'] }
```

4. 刷新浏览器 —— 广场上会自动多出一座通往新关卡的传送门 🎉

**玩法越特别，越推荐把数据单独放**，例如出题内容放 `src/content/banks/`（像谜语那样），
关卡文件只写「怎么玩」。

> 详细的 `ctx` 接口、积木函数清单、存档规范、常见坑，都在 `AGENTS.md`。

### 题库：想加多少加多少，分类放在本地文件里

现在有**两个题库**：谜语（第 1 关用）和常识（第 2 关开宝箱用）。
它们都放在本地文件里，用记事本 / VS Code 直接编辑就行。

谜语不是在代码里，而是按**分类**放在这些**本地文件**里，用记事本 / VS Code 直接编辑就行：

```
src/content/banks/
├── index.js                题库清单（新加分类，要在这里加一行）
└── riddles/
    ├── animals.js          动物（10 条）
    ├── plants.js           花草树木（9 条）
    ├── nature.js           天气与自然（9 条）
    ├── food.js             吃的喝的（9 条）
    ├── things.js           生活用品（10 条）
    ├── body.js             身体与穿着（8 条）
    └── characters.js       汉字字谜（10 条）
```

**加一条谜语**：打开对应的文件，照着已有的格式，在一个 `{ ... }` 后面加一个 `{ ... }`：

```js
{
  id: 'pingpong',                       // 唯一的英文 id（以后别改，改了小朋友这道题的进度会清零）
  emoji: '🏓',                          // 只是装饰，游戏里不显示（怕泄露答案）
  q: '圆圆一张小桌子，两人对着打小球；一左一右来回打，谁也不许用手接。',
  a: '乒乓球',                           // 正确答案
  options: ['羽毛球', '乒乓球', '篮球'],  // 三个选项，必须包含正确答案
  hint: '它是我们国家的国球，要在桌子上打。'   // 答错时给的提示（别说破答案）
}
```

**加一个新分类**（比如「交通工具」）：把 `animals.js` 复制成 `vehicles.js` →
把第一行的 `'animals', '动物'` 改成 `'vehicles', '交通工具'` → 换上新的谜语 →
最后在 `src/content/banks/index.js` 的清单里加一行 `'content/banks/riddles/vehicles.js',`。
刷新浏览器，新谜语就会出现在抽题池里了。

**常识题库**在 `src/content/banks/commonsense/`，格式和谜语一样，只是加上题库名：

```
src/content/banks/commonsense/
├── life.js         生活常识（10 条）
├── safety.js       安全常识（10 条）
├── nature.js       自然常识（10 条）
└── society.js      节日与习俗（8 条）
```

```js
Game.registerQuestions('commonsense', 'life', '生活常识', [
  {
    id: 'wash-hands',                       // 唯一英文 id
    q: '吃饭前应该先做什么？',                // 题目（面板上只显示文字，别放图案）
    a: '洗手',                              // 正确答案
    options: ['洗手', '看电视', '跑步'],      // 三个选项，必须包含正确答案
    hint: '手上有很多看不见的细菌。'           // 答错时的提示
  },
  // …后面继续加
]);
```

想加**全新的题库大类**（例如口算）：新建一个文件，用
`Game.registerQuestions('math', 'add', '加法', [ ... ])`，
再到 `src/content/banks/index.js` 加一行，关卡里就能用
`Game.pickQuestions(1, { bank: 'math' })` 抽题了。

> 细节（随机抽题规则、题目 id 与存档、怎么加分类）写在 `AGENTS.md` 第 8 节。

## 九、想和多个 AI 一起做？（多 Agent 并行）

关卡是「一天 1~2 个」做出来的，所以这套仓库专门支持**多人 / 多 AI 同时开工**：

| 想要 | 看这里 |
| --- | --- |
| 一次把「今天想做什么」说清楚 | `docs/工作流程.md`（口述 → 设计卡 → 开发 → 试玩验收，含证据分级 E0/E1/E2） |
| 关卡设计卡的写法与机制映射词典 | `docs/关卡设计规范.md` + `levels/`（一人一卡） |
| 让几个 AI 分工（策划 / 引擎 / 关卡 / 题库 / 测试 / 文档） | `agents/README.md` + `agents/*.md`（开新会话时贴进去） |
| 谁在做什么、做到哪了 | `program/BOARD.md`（看板，唯一事实源） |
| 任务卡怎么写 / 怎么验收 | `program/tasks/_TEMPLATE.md`，样例：`TC-0001` / `TC-0002` |
| 以前的决定 / 每版改了什么 | `program/DECISIONS.md` / `program/CHANGELOG.md` |
| 并行细则（分支 / worktree / 冲突怎么办） | `docs/COORDINATION.md` |

**三条最要紧的规矩**（全文在 `AGENTS.md` 第 3 节）：

1. **一个文件一个写者**：亲手改的文件不能超过自己名下的范围，想改别人的先发一张 CHANG E 卡。
2. **协调官不动手**：负责派卡的那位（人或 AI）只改看板，不写代码。
3. **只有测试角色能把卡判为完成**：必须贴「命令 + 输出」，不许说「应该没问题」。

**谁来写代码？** 小朋友只负责「讲玩法 + 试玩验收」；家长负责转写与拍板；
AI 负责把设计卡翻译成 `src/levels/` 里的关卡。
