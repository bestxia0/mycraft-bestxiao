# answers · 谜题答案封存

这个目录存放谜题关的**答案**，目的是让答案在**关卡内不可见**。

## 硬规则（来自小朋友原话）

> "你不要给我设置答案。"
> "如果错了，你再给我看答案。"
> "如果你在上面设置了答案，我就有点搞不懂你把答案放出来是干嘛的。"

因此：

1. 答案**只能**写在本目录，不许出现在 `levels/`、`transcripts/` 的关卡内容里。
2. 游戏脚本、场景装饰、字幕、提示语中**不得包含答案文本**。
3. 游戏**不自动揭示**答案。只有小朋友猜错了，由大人查看本目录后口头告诉他。
4. 小朋友答对/答错都记录到关卡设计卡的"试玩记录"，用来调难度。

## 命名

`L<序号>-答案.md`，与关卡设计卡一一对应（序号 = **游戏内顺序**，见 `levels/README.md`）。

## 现在的情况（2026-10-24）

- 游戏里唯一的答题关卡是 **L01 谜语森林**，它的谜底**存在题库文件里**
  （`src/content/banks/riddles/*.js` 的 `a` 字段），不放在本目录 —— 因为题库本来就不给玩家看。
- 「不预置答案」这条硬约束，在游戏里是这样落地的：
  1. 谜语面板**只显示文字，不显示图案**（图案会泄露答案，见 `program/DECISIONS.md` D-004）；
  2. 答错只说「再想想」并给一句提示，**不揭示答案**；
  3. 玩家答完就关面板，答案不会留在屏幕上。
- 本目录（`levels/answers/`）留给**以后做纯口答题**的关卡用：那种答案不进游戏，只给大人查。

## 提醒

这里是**剧透文件**。给小朋友看屏幕时，不要打开这个目录。
