## 场景

一大片**沙漠**，四周有看不见的边界（跑不出去）。西边偏北有一片**绿洲**，
绿洲上立着一座石拱门 —— 那就是沙漠的出口。出生点在沙漠南边，旁边就是回小镇的传送门。

天上挂着太阳，远处有沙丘、石头、枯草和大仙人掌当地标。地上有会自己游走的**小龙卷风**。

## 道具

| 道具 | 作用 | 从哪来 |
|------|------|--------|
| 小马 | 骑上去跑，比走路快一倍 | 出生点周围先摆 8 匹；之后每 16 秒随机跑来 1 匹（最多 12 匹） |
| 头上的箭头 | 指「大概方向」 | 自动跟着玩家，一直指着出口附近（会左右晃） |
| 小龙卷风 | 挡路：卷到会被吹起来 | 沙漠里 4 处，会自己游走 |
| 仙人掌 | 挡路：贴上去会被扎 | 沙漠里散着长，按 F 可以打碎 |
| 小蛇 | 会咬人：按 F 能把它打飞 | 沙漠里散着爬 |
| 绿洲石拱门 | 出口 | 沙漠西北边 |

## 动作

1. 从广场进传送门 → 落到沙漠南边（**一进沙漠就开始倒计时**）
2. 找一匹小马，走到跟前**按 F**（打它一下）→ 骑上去
3. 骑上马用 **W A S D** 跑，照着头上箭头的**大概方向**找出口
4. 路上躲开小龙卷风，绕开或打碎挡路的仙人掌，把小蛇打飞
5. 跑到西边偏北的绿洲石拱门 → **逃出沙漠**

## 目标（怎么算过关）

2 分钟之内骑着马跑到绿洲拱门。

## 规则（硬约束，来自小朋友原话）

- **2 分钟倒计时**：从进沙漠那一刻开始算，不是从骑上马开始算。
- **超时自动送回小镇**：不弹「失败 / 重试」面板，直接把小朋友传送回广场，
  想再玩就再进一次关。这是小朋友原话「自动将你传送回小镇，让你重新来这一关」。
- **头上箭头只给大概方向**：允许偏，偏到「看得出大方向、但会走一点弯路」的程度
  （现值 ±18° 以内摆动，实测 0.3°~15.9°，**不是**精确指向）。
- **马会随机生成**：不是固定几匹，玩着玩着会有新马跑过来。
- 被打到**不掉血、不会失败**：仙人掌扎一下、蛇咬一口、龙卷风卷一下，
  最坏的结果是被卷下马（再找一匹马骑上去就行），倒计时不等人。
- 不想骑马也能走（走得慢，多半走不出去）—— 允许小朋友自己试，不劝也不拦。

## 玩法与参数（E2：实现者定的，可调）

参数都在 `src/levels/desert-escape/level.js` 顶部「参数表」里，改完跑一次 `test-desert.sh`。

| 项目 | 值 | 为什么 |
|------|-----|--------|
| 限时 | 120 秒 | 小朋友说的 2 分钟 |
| 出生点到出口 | 直线约 283 步 | 骑马直线约 24 秒能到 → 中间有得玩，又不至于跑不到 |
| 走路 / 骑马速度 | 6.2 / 12 步每秒 | 纯走路直线也要 46 秒；骑马快一倍，留出探索的余量 |
| 骑马按 F | **冲刺**（1.7 倍，1.5 秒，冷却 4.5 秒） | 骑马时 F 空着，给他一个「马跑快点」的爽点 |
| 按 E | 下马（想下来休息 / 再打蛇用） | 骑马时打不到地上的蛇和仙人掌 |
| 箭头偏差 | ±0.32 弧度（≈±18°） | 「大概方向」但不至于把人带丢 |
| 通关奖励 | 30 🪙；打飞小蛇 2 🪙；打碎仙人掌 1 🪙 | 和前面几关的金币量级一致 |
| 记录 | 最快一次用时、逃出次数、超时次数 | 下次来能看到自己进步 |

## 机制映射（给实现用）

| 玩法 | 实现手段 | 触发 → 变化 → 反馈 |
|------|----------|--------------------|
| 按 F 骑马 | 判定最近的马（3.6 步内）→ `mount()` | 按 F → 玩家被钉在马背上（抬到 y=1.6）、马的牌子藏起来、马听 WASD → 音效 + 提示 |
| 骑马移动 | 关卡接管玩家位置（玩家自己的走路那一帧不算） | 按 WASD → 马朝镜头前方跑、腿摆得快 → 相机跟着 |
| 骑马冲刺 | 骑马时按 F | 按 F → 1.7 倍速跑 1.5 秒 → 💨 提示，4.5 秒冷却 |
| 大概方向的箭头 | 引擎头顶指引箭头指向 `objective.target`；这个 target 每帧按 `base + 摆动` 算 | 每帧 → 箭头绕着正确方向左右晃 → 只有大方向是对的 |
| 倒计时 | 引擎顶部计时条 `Game.UI.battle({ time })` | 每帧 → 顶部 mm:ss，剩 30 秒变红闪 |
| 超时 | `fail()`：`leaving = true` → 1.7 秒后 `ctx.goHub()` | 倒计时到 0 → 音效 + 提示气泡 → 自动回广场，`attempts + 1` |
| 出口 | `ctx.zone({ x, z, r, once })` | 骑马进拱门 → 🏝 通关面板（用时 / 骑马次数 / 打飞小蛇 / 最快一次 / 金币） |
| 小龙卷风 | 4 个沙柱，自己按 `dir + turn` 游走 | 每帧游走 + 自转 → 走到 5.5 步内 → 被吹起来；**骑着马会被卷下马**（马被挪开 8 步） |
| 仙人掌 | 散落 + 3 棵超大当路标；每棵一个碰撞盒 | 贴到 1.7 步 → 被扎、弹开；按 F（3 步内）→ 打碎，**碰撞盒关掉**路就通了，掉 1 🪙 |
| 小蛇 | 4 节方块身体 + 左右扭 | 贴到 1.5 步 → 被咬、弹开、僵直；按 F（3 步内）→ 被打飞 + 惯性滑走，掉 2 🪙 |
| 马会随机生成 | `horseTimer` 每 16 秒补 1 匹（上限 12） | 到点 → 在玩家 16~40 步外找个空地冒出来 → 🐎 提示 + 音效 |
| 重新进关 | `onEnter()` 全部重置 | 再进关 → 倒计时归 120、马回到原位、牌子挂回来、出口还能再触发 |
