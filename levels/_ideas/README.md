# _ideas · 还没做进游戏的点子

这里放**小朋友口述过、但游戏里还没有**的玩法点子。

## 和 `levels/` 根目录的区别

| 目录 | 是什么 | 编号 |
|------|--------|------|
| `levels/`（根） | **游戏里真实存在的关卡**的说明书 | 卡号 = 游戏内顺序（以 `src/levels/index.js` 为准） |
| `levels/_ideas/`（这里） | 还没实现的点子 | **没有卡号**，用「日期 + 名字」当文件名 |

> 2026-10-24 之前，这些点子曾经占用过 `L01`~`L05` 的卡号，
> 和游戏里真正的第 1~5 关撞在一起，很容易看错。现在分开了。

## 规则

1. 点子文件里必须写清「状态：未实现」和「来源（哪天的口述）」。
2. 点子**落地成代码**之后：在 `levels/` 里开一张正式卡，回到这里把状态改成
   「已落地 → 见 L0X」，文件**保留**（它是最初的设计依据）。
3. 点子里的机制如果被别的关卡用了，也在这里说一声（例：猜谜语 → L01 谜语森林）。
4. 想挑点子开工：先去 `program/ROADMAP.md` 看优先级，然后在 `program/tasks/` 开一张任务卡。
