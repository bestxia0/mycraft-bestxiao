## 原话（E0）

> "第8关。我们要把风扇装进旁边的小房子里面。但是我们有一个充电器，万一找不到的话，
> 就可以回主世界去找一下。如果找到了，就回到那个地方去。如果你还是找不到，还是可以重新去找一下下。
> 找到以后，就要直接装到房间里去充电。要是没装的话，你就过不了关。
> 这是一个小的，我们可以用缩小能力，进去看看里面的样子。
> 前面又有一个白色的空调位置。但如果你把它装进去了，也没找到空调充电器，那就不用找它了，
> 万一它本来就是有电的呢？那个房间有一个门。也有窗户。"

家长附的编号（E1）：「第 8 关」。

## 场景

一片**清亮白天的小院子**（52 × 52 步，四周是草地、树、花、蘑菇、石头，天上有云）。
院子中间偏北是**一栋小木屋**（外墙 12 × 10 步、墙高 3.4 步、屋顶还挑出 1.2 步的屋檐），
**南面有门、有窗**：门洞只有 **2.4 宽 × 1.2 步高**（大个子 1.8 步高 → 钻不进去），
南面两扇窗 + 东面一扇窗（装饰）。

出生点在院子南边（`0, 16`），一进关就看见小屋和一条通向门口的土路；
回小镇的传送门在出生点**侧面**（`-8, 16`，不在镜头正后方）。

屋里：木地板 + 一块小地毯 + 一张小桌子 + 一张小凳子 + 墙上小架子、
**西边地上的蓝圈（风扇位）** + 墙上插座、**东边墙上那块白色的空调位**、屋顶一盏吊灯。
小屋**后面**堆着两个木箱，旁边立着一块牌子 —— **风扇被风刮到屋后去了**（要自己绕过去找）。

## 道具

| 道具 | 作用 | 从哪来 |
|------|------|--------|
| 风扇 | 装进屋里地上的蓝圈（风扇位），通电后会转 | **小屋后面**（绕过去按 `E` 抱起来） |
| 充电器 | 给风扇通电 | **不在这一关**：回主世界（广场**东边的工具台**）按 `E` 借一个 |
| 门（2.4 × 1.2 步） | 进屋的唯一入口；**门太小，大个子进不去** | 小屋南面；按 `E` 变小 / 按 `R` 变小 |
| 风扇位（蓝圈）+ 插座 | 装风扇、插电的地方 | 屋里西边地上 / 西墙上 |
| 白色的空调位 | **彩蛋**：通电以后自己就亮了，不用找空调充电器 | 屋里东墙 |
| 回小镇的传送门 | 随时回广场（也是去借充电器的那条路） | 出生点旁边 |
| 木牌 ×3 | 写着玩法（按 R 变小 / 风扇在屋后 / 关卡名） | 出生点旁、门口旁、屋后 |

## 动作

1. 从广场进传送门 → 落到院子里（**没有时间限制**，可以慢慢玩）
2. 先找风扇：看一眼任务条（「听说风扇被风刮到小屋后面去了」），**绕到小屋后面**，
   走到风扇跟前按 `E` **抱起来**（这一关**故意不给头顶箭头**，重点就是「找」）
3. 走到小屋门口 → 按 `E`（或直接按 `R`）**变小** → 从 1.2 步高的门洞**钻进屋**
4. 走到地上那个**蓝圈**旁边按 `E` → **风扇装好了**（可是没有电）
5. 回广场：走回传送门按 `E` → 到广场**东边的工具台**按 `E` **借充电器**
   （任务条和头顶箭头都会指向工具台）
6. 再进小屋 → 变小进屋 → 到**风扇位**按 `E` **插上充电器** → **通电！**
   → 风扇转起来、吊灯亮、**墙上的空调位自己亮了** → **通关（+60 🪙）**

## 目标（怎么算过关）

**把风扇装进小屋的风扇位、并且通上电**（= 风扇转起来）。
小朋友的原话是硬规则：**"要是没装的话，你就过不了关"** ——
没抱到风扇 / 没装上 / 没通电，怎么按都不会通关。

## 规则（硬约束，来自小朋友原话）

- **要装进房间里**：风扇不是装在外面，要装进**屋里**地上的蓝圈上；
  而进屋**必须变小**（门洞 1.2 步高 < 大个子 1.8 步高），所以「变小」是必经动作。
- **充电器要回主世界找**（小朋友说的「回主世界去找一下」）：
  充电器**不在第 8 关**，在中央广场东边的工具台；**来回跑几趟都欢迎**
  （小朋友说的「还是可以重新去找一下下」）—— 风扇装好之后再回广场，风扇**还留在屋里**。
- **没装就过不了关**：装好 + 有电 = 通关，缺一样都不行（三次按 E 的提示都不一样）。
- **白色的空调位不用找空调充电器**：小朋友说的「万一它本来就是有电的呢」——
  风扇一通电它就自己亮，**纯彩蛋，不影响通关**。
- **有一个门，也有窗户**：门是真的能进出的门洞；窗户是装饰（不能爬）。
- **不给全程答案**：没找到风扇之前**不显示头顶箭头**（第 2 关宝箱山谷也是这个理念，见 D-003）；
  找到风扇之后箭头才开始指「该去哪儿」（门口 → 回广场的门 → 风扇位）——见 D-012。

## 玩法与参数（E2：实现者定的，可调）

参数都在 `src/levels/fan-cottage/level.js` 顶部「参数表」里，改完跑一次 `test-cottage.sh`。

| 项目 | 值 | 为什么 |
|------|-----|--------|
| 院子大小 | 52 × 52 步（±26） | 够跑开，来回借充电器也不至于跑太久 |
| 小屋 | 12 × 10 步外墙、墙高 3.4、屋檐挑出 1.2 | 小朋友说的「一个小房子」，站在外面一眼看得完 |
| **门洞** | **2.4 宽 × 1.2 步高** | 关键数值：大个子 1.8 步、小人 0.6 步 —— **只有变小才进得去** |
| 缩小倍率 | 34%（1.8 → 0.61 步），碰撞盒半径 0.34 → 0.16 | 缩得太小会看不清、太大又钻不过门 |
| 小人走路 / 跳 | 3.4 步每秒 / 起跳 6.6 | 小人腿短，速度本来就该慢一点（大个子 6.2） |
| 小人镜头 | 自动拉近到 3.0 步、看的高度降到 0.5 | 不然镜头会对着空气，屋里什么都看不见 |
| 风扇藏在哪 | 屋后 `(3.4, -15.8)`，旁边两个木箱 | 小朋友说的「万一找不到」—— 要绕过去才看得到 |
| 借充电器的地方 | 广场东边工具台 `(15, -8)` | 小朋友说的「回主世界去找一下」 |
| 通关奖励 | 60 🪙 | 比前面的关卡多一点（这一关要来回跑，路费） |
| 时限 | **没有**（不限时） | 家长那句「5 分钟左右」是**目标体验时长**，不是硬倒计时；这一关考的是「找 + 搬 + 装」，不催 |
| 记录 | 这一局花了多少秒、通电次数、进来过几次 | 下次来能看到自己快了多少 |

**时间预算**：把「找风扇 → 变小进屋 → 装好 → 回广场借充电器 → 再进屋插电」这一整条走完，
**纯走路 184 步 ≈ 31 秒**（脚本量过），加上找东西、看牌子、来回几趟，
实际玩起来落在 **3~5 分钟**（对得上家长说的「5 分钟左右」）。

## 机制映射（给实现用）

| 玩法 | 实现手段 | 触发 → 变化 → 反馈 |
|------|----------|--------------------|
| **缩小能力**（按 R 变小） | 引擎新增关卡字段 `shrink: true` → `player.setShrinkEnabled(true)`；`toggleShrink()` 同时改碰撞盒高/半径、模型缩放、镜头距离 | 按 `R`（手机点「小」）→ 唰一声变小 + 镜头凑近；再按变回来 |
| 门太小，大个子进不去 | 门楣碰撞盒从 y=1.2 到 3.4 是实的，门洞只有 1.2 步高 | 大个子朝门走 → **撞住停在门口**（z≈-2.66）；变小后 → 直接走进屋（z≈-10.1） |
| 找不到风扇要自己找 | 风扇放在**屋后**，旁边两个木箱挡着；没找到之前 `objective()` **不返回 target**（不给箭头） | 绕到屋后 → 看见风扇 + 牌子 |
| 抱起风扇 | `ctx.interact`（半径 2.4）→ 写 `save.flag('fanFound')` | 按 `E` → 叮一声 + 粒子 + 一句话提示 + 任务条更新 |
| 回主世界找充电器 | **引擎新增全局开关** `Game.Save.flag/setFlag`（存在 `profile().global.flags`，跨关卡共用）+ 广场东边工具台的交互 | 广场按 `E` 借 → 台子上那个充电器消失 + 全局 `hasCharger = true` |
| 来回跑几趟都行 | 风扇/充电器的状态存在**存档**里，不放在关卡运行时数据里 | 回广场再回小屋 → 风扇还装在屋里、充电器还在手上 |
| 装进房间 | `ctx.interact`（风扇位，半径 2.0）→ 写 `fanMounted`，把风扇摆到蓝圈上 | 按 `E` → 风扇出现在地上 + 「可是没有电…」 |
| 充电通电 | 风扇位按 `E`：有风扇 → 装；装了没充电器 → 提示回广场；都齐 → `powered = true` | 按 `E` → 风扇转起来 + 拉一根电线到插座 + 吊灯亮 + `ctx.complete()` |
| **空调位自己亮**（彩蛋） | `house.powerOn()`：空调材质变色 / 自发光 + 冷气片出现 + 牌子换成「❄ 空调位 · 自己亮了」 | 通电那一刻 → 空调位亮起来，**不用找空调充电器** |
| 屋里有门有窗 | 南墙拆成「左右两段 + 门楣」留出门洞；窗是贴墙的装饰方块（`collide:false`） | 看起来像一个真房间，不是四个盒子 |
| 进屋看得清（★踩过的坑★） | 屋顶两块盒子 `{cast:false}` **不投影**（否则整间屋子罩在阴影里，黑得看不见）；吊灯留 0.55 的基础亮度，通电加到 2.0 | 变小钻进去 → 地板、蓝圈、风扇都看得清 |
| 没找到风扇不给箭头 | `objective()` 在 `fanFound` 之前不返回 `target` | 任务条只给一句话（「绕过去找一找～」），头上没有箭头 |
| 再玩一次 | `onEnter()`：上一局已经通电 → 把 `powered / fanMounted / fanFound` 清掉重新摆（风扇回屋后） | 再进关 → 又是没通电的小屋，可以重玩 |
| 每次都是大个子进场 | `director.go()` 里 `setShrinkEnabled()` 会先 `setSmall(false)` | 变小着回广场再进小屋 → 又是大个子（要变小得自己按） |

## 待确认（E2）

- [ ] **门洞 1.2 步 / 缩小倍率 0.34 合不合适？**（现在是大个子怎么挤都进不去、小人轻松过；
      觉得太卡就把 `P.DOOR_H` 调到 1.4，或者把缩小倍率调到 0.4）
- [ ] **风扇藏在屋后**是不是太难 / 太容易？（现在有一块牌子和任务条文字兜底；也可以改成随机藏在屋后左/右）
- [ ] **充电器放在广场东边的工具台**（而不是第 8 关里的某个角落）对不对？
      小朋友原话是「回主世界去找」——但如果他嫌来回跑麻烦，也可以改成「工具台就在院子门口」
- [ ] **空调位自己亮**（不用找空调充电器）是不是他要的意思？
      （原话「万一它本来就是有电的呢」听起来就是这个意思，但那是**彩蛋**，不通关也要解释清楚）
- [ ] **不限时**对不对？（家长说的是「5 分钟左右能完成」；现在是「玩法走完约 3~5 分钟」，
      没做倒计时 —— 如果小朋友喜欢有计时，可以加一条「挑战模式」的倒计时）
- [ ] 通电之后要不要**真的吹风**（让小朋友感觉到风 / 屋里变凉）？
      （现在只有风扇转 + 吊灯亮 + 冷气片，是视觉上的）
- [ ] 工具台借充电器要不要「还回去 / 只能借一次」的规矩？（现在是**借一次就永久在身上**，不限时间）
- [ ] 点子池里那条「迷宫里找钥匙」和这一关的「找零件 → 装 → 通电」是同一类**跑腿 + 安装**玩法，
      以后要不要抽一个通用的「零件任务」引擎能力？（现在只有第 8 关用得上）
