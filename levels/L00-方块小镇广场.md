## 场景

一块开放式的大空地，出生在南边小路上：

| 在哪 | 是什么 |
|------|--------|
| 中间 | 石板广场（40 × 24），站着**村长爷爷**和一块玩法木牌 |
| 东边 | **跳跳乐**：三级石台，一级一级跳上去，顶上有 🏆 金杯 |
| 西边 | **小迷宫**：木头栅栏围的一圈一圈，正中间藏一个宝箱 |
| 南边 | **许愿池**（半径 5）+ **小花园** |
| 四周 | 树林、石头、8 枚闪光金币 |
| 广场尽头 | **一排传送门**：按关卡数量自动排好，通关一关，下一座门就亮起来 |

## 道具

| 道具 | 作用 | 从哪来 |

| 传送门 | 进入各个关卡 | 自动生成（按 `src/levels/index.js` 的清单） |
| 8 枚金币 | 每枚 +3 🪙 | 散在镇上，**每次进小镇都重新出现** |
| 金杯 🏆 | +30 🪙 | 跳到跳跳乐最顶上 |
| 迷宫宝箱 🎁 | +25 🪙 | 走到迷宫正中间，每份存档只能拿一次 |
| 许愿池 | 投 10 🪙 许个愿 | 走到池边按 E |
| 村长爷爷 👴 | 告诉你去哪玩 | 按 E 说话 |

## 动作

1. 出生在小镇南边 → 捡路上的金币
2. 想闯关：走到亮的传送门前面按 E
3. 不想闯关：跳跳乐 / 小迷宫 / 许愿池 / 小花园随便玩

## 目标（怎么算「完成」）

广场没有通关概念。头顶箭头和任务条指的是**现在该去的地方**：
代码里用 `Game.Levels.currentTarget(save)` —— 第一个「没通关又已经解锁」的关卡。

## 规则

- **解锁规则**：某一关要**上一关通关**才开（`Game.Levels.isUnlocked`；第一关默认开着）。
  门有三种样子：`locked` 灰着 / `open` 亮着 / `done` 已通关。
- **传送门自动生成**：加一个新关卡只要改 `src/levels/index.js`，广场**一行都不用动**。
- 捡过的金币每次回小镇都会重新摆出来（小朋友每次进镇都有东西捡）。
- 广场里**不会失败**：掉进水池、走进迷宫都能自己走回来。
