## 原话（E0）

> "设计一个比较大的迷宫， 不能跳跃，保证一定有出口， 有多套迷宫随机。"
> "中中间有随机怪物出现。 需要攻击，杀死后可获得一定金币和装备。 有时间要求走到出口。"

家长附的编号（E1）：「第 7 关 迷宫」。

## 场景

一片**石头铺的迷宫**（21 × 21 格、一格 3 步 = **63 × 63 步**，相当于 10 × 10 个迷宫格），
四周是草地、树、花和石头，天上飘着云，天气是清亮的白天。
**墙有 3 步高**，跳起来也翻不过去（这一关本来就跳不起来）。

出生点在迷宫**西南角的门外**，旁边有回小镇的传送门和两块木牌（写着玩法和按键）。
**出口在迷宫东北角或者西北角**（每次进关随机一座），门上有 12 步高的绿色光柱，
**隔着迷宫墙也看得到「出口在这一头」** —— 但怎么绕过去要自己走。

**每次进关都是一座新的迷宫**（随机种子），同一颗种子 = 同一座迷宫。

## 道具

| 道具 | 作用 | 从哪来 |
|------|------|--------|
| 迷宫墙 | 挡住路、不能跳跃越过 | 每次进关按随机种子重新生成，绕成一座「完美迷宫」 |
| 两个候选出口 | 只有 1 座亮着；走进去就通关 | 东北角 / 西北角，每次进关随机亮一座 |
| 绿色光柱 | 隔着墙也能看见出口在哪个方向 | 挂在亮着的那座出口上 |
| 小怪兽（8 只） | 会溜达、会发现你、会追、会咬（只推人不掉血） | 随机撒在离入口至少 8 格的走廊里 |
| 金币（18 枚） | 走过去自动捡，一枚 +3 🪙 | 撒在走廊里，其中 1/3 故意放在死胡同 |
| 头上的箭头 | **最后 45 秒**才开始指向出口 | 引擎头顶指引箭头（前 135 秒故意不给） |
| 回小镇的传送门 | 随时能回广场 | 出生点侧面 |

## 动作

1. 从广场进传送门 → 落到迷宫的西南门外（**一进关就开始 3 分钟倒计时**）
2. 从南边的门口走进去，看绿色光柱判断出口在东北还是西北，开始找路
3. 路上遇到小怪兽：**按 `F`** 打它（一只 4 下；拿了好武器几下就打完）
   → 打死掉 3~6 🪙，还有 60% 的概率掉一件装备
4. 顺手把走廊里的金币捡了（有些藏在死胡同里）
5. 剩最后 45 秒时，头上的箭头开始指向出口 —— 跟着箭头跑
6. 走到亮着的那座出口 → 通关（+50 🪙）

## 目标（怎么算过关）

**在 3 分钟内走到亮着的那座出口**（走进 2.4 步以内算到）。
迷宫**一定连通**（算法保证），所以出口**一定走得到**，不会出现「无解」的情况。

## 规则（硬约束，来自小朋友原话）

- **不能跳跃**：这一关按 `空格` 不会跳（墙 3 步高，跳也翻不过去）；
  屏幕下方的操作说明会变成「……（这一关不能跳）」。**别的关卡照样能跳，手感没变**。
- **保证一定有出口**：迷宫用深度优先（递归回溯）挖出来，是「完美迷宫」——
  任意两格之间都有且只有一条路，所以**出口一定走得到**（脚本跑 30 颗种子验证连通性）。
- **有多套迷宫随机**：每次进关换一颗种子 = 换一座迷宫（同一颗种子永远是同一座，方便复现）。
- **中间有随机怪物**：8 只小怪兽随机撒在迷宫里（离入口至少 8 格，别堵门），
  **按 `F` 打**（一只 4 下），打死**必掉 3~6 金币**，**60% 掉一件装备**
  （普通 60% / 稀有 30% / 史诗 10%）。
- **有时间要求走到出口**：**3 分钟**倒计时，一进关就开始；时间到还没走出去 →
  **不弹失败面板**，1.7 秒后自动回小镇重来（和第 5、6 关一个规矩），记一次 `attempts`。
- **中间可以有金币出现**：场上 18 枚金币，其中 1/3 放在死胡同里（愿意绕路就有奖励）。
- **不给全程答案**：前 135 秒**不给**出口箭头（迷宫要自己走才有意思），
  只剩最后 45 秒才给箭头兜底（怕小朋友绕到没脾气）—— 见 D-011。

## 玩法与参数（E2：实现者定的，可调）

参数都在 `src/levels/stone-maze/level.js` 顶部「参数表」里，改完跑一次 `test-maze.sh`。

| 项目 | 值 | 为什么 |
|------|-----|--------|
| 迷宫大小 | 10 × 10 个迷宫格 → 21 × 21 格 = **63 × 63 步** | 小朋友说的「比较大的迷宫」 |
| 一格边长 | 3 步 | 走廊够宽，第三人称镜头不憋屈 |
| 墙高 | 3 步 | 「不能跳跃」要真的翻不过去 |
| 限时 | 180 秒（3 分钟） | 最短路径 17~60 秒，留出绕路 / 打怪 / 捡金币的余量 |
| 出口箭头 | 剩 45 秒才开始指 | 前面不给（迷宫要自己走），最后兜底 |
| 小怪兽 | 8 只 / 4 血 | 走廊够长不挤，空手 4 下一只 |
| 怪兽位置 | 离入口 ≥ 8 格、彼此 ≥ 4 步 | 别堵在门口、别叠在一起 |
| 怪兽速度 | 溜达 1.9 / 追人 3.4 步每秒 | 比走路（6.2 步每秒）慢，跑得掉 |
| 咬人 | 贴到 1.7 步内推一把，1.6 秒冷却 | **不掉血、不会失败**，只是催小朋友按 F 打它 |
| 金币 | 18 枚、一枚 3 🪙，1/3 在死胡同 | 小朋友说的「中间可以有金币出现」 |
| 打死怪兽掉落 | 3~6 🪙 必掉 + 60% 掉装备 | 小朋友说的「可获得一定金币和装备」 |
| 通关奖励 | 50 🪙 | 和前面几关的金币量级一致 |
| 记录 | 最快一次用时、通关次数、累计打怪 / 捡币 | 下次来能看到自己进步 |
| 迷宫随机度 | 打通 25% 的死胡同（braid） | 全是死胡同会走得很闷，留一点回路更活 |

**时间预算（重要）**：不同迷宫的「最短路」差得挺多 —— 跑测试见到的范围是
**105 ~ 363 步（约 17 ~ 60 秒）**，限时 180 秒
—— **余量基本都花在绕路 / 打怪 / 捡金币上**，不是用来赶路的。

## 机制映射（给实现用）

| 玩法 | 实现手段 | 触发 → 变化 → 反馈 |
|------|----------|--------------------|
| 造一座保证连通的迷宫 | `props.js` 的 `generate()`：深度优先递归回溯挖通（完美迷宫）+ 随机打通 25% 死胡同 | 进关 → 得到一张 21 × 21 的 `Uint8Array`（1 墙 / 0 可走） |
| 每次换一座 | `mulberry32(seed)` 可复现随机数；`onEnter` 每次抽新种子 | 再进关 → 新种子 → 新迷宫（同种子 = 同迷宫，测试可复现） |
| 「保证一定有出口」 | `bfs(entrance)` 数走过的格子，`reached === openCount` 才算连通 | 生成后立刻自检 → 脚本用 30 颗种子验证出口都走得到 |
| 墙（省 Mesh） | `buildWalls()` 把**同一行连续的墙合并成一条长条**（21 行 → 约 110~130 条） | 进关 → 一批 Mesh + 一批碰撞盒；再进关整批换掉 |
| **不能跳跃** | 引擎新增关卡字段 `noJump: true` → `player.jumpEnabled = false` | 进关 → 按空格不再跳；底部操作说明同步改成「这一关不能跳」 |
| 出口只有一座亮着 | 两个候选出口都造好、都藏起来；`onEnter` 用关卡自己的随机数挑一座 `visible = true` | 进关 → 1 座绿的 + 12 步绿色光柱（隔墙可见） |
| 3 分钟倒计时 | 引擎顶部计时条 `Game.UI.battle({ time })` | 每帧 → 顶部 mm:ss；通关 / 超时停表 |
| 前段不给箭头 | `objective()` 只有 `timeLeft <= 45` 才返回 `target` | 剩 45 秒 → 顶部箭头出现 + 一句话提示 |
| 按 F 打怪兽 | `ctx.player.consumeAttack()` + 挥刀方向点积；**背对着按也兜底打最近的那只** | 按 F → 掉血 + 白闪 + 粒子 + 震屏；血条见底 → 倒下 |
| 打死掉东西 | `hurtMonster()`：`addCoins(3~6)` + 60% `grantItem(rollDrop())` | 打死 → 金币进账 + 飘「💥 打倒一只…+4 🪙，掉了「⚔️ 铁剑」」 |
| 武器越打越疼 | `weaponDamage()` 看背包里最稀有的那件（空手 1 / 普通 1 / 稀有 2 / 史诗 3 / 传说 4） | 进关 → `player.setTier(最好那件 - 1)`；炼出传说之剑后一下打 4 血 |
| 捡金币 | 每帧量距离 < 1.7 步 → `takeCoin()`（+3 🪙、粒子、从场上摘掉） | 走过去 → 自动捡 + 任务条上的金币数 +1 |
| 怪兽会追人 | 9 步内 + 一眼看得到（`lineOfSight`）→ 按「离玩家更近的下一格」走，速度换 3.4 | 看见你 → 追过来，贴到 1.7 步内咬一口（推人 + 提示按 F） |
| 走到出口通关 | `update()` 每帧量「玩家 ↔ 亮着的出口」距离 < 2.4 步 → `win()` | 走进去 → 闪绿 + 粒子 + 结算面板 + 50 🪙 |
| 时间到 | `fail()`：`leaving = true` → 1.7 秒后 `ctx.goHub()`，`attempts + 1` | 倒计时归零 → 音效 + 一句话提示 → 自动回广场 |
| 再进一次 | `onEnter()` 全部重置 | 再进关 → 新迷宫 / 倒计时 180 / 金币和怪兽都回来 |

## 待确认（E2）

- [ ] **3 分钟**够不够？（小朋友只说「有时间要求」，家长那句是「5 分钟左右」；
      实测最短路 17~60 秒、加上绕路和打怪大概 1~2 分钟。觉得紧就把 `TIME_LIMIT` 调到 240）
- [ ] **63 × 63 步**是不是太大 / 太小？（10 × 10 迷宫格；想简单点把 `COLS` / `ROWS` 调到 8）
- [ ] **45 秒才给箭头**会不会太晚？（`HINT_AT`；也可以改成「走错很多次就给」）
- [ ] 小怪兽 **8 只 / 4 血**合不合适？（空手 4 下一只；太多会耽误时间）
- [ ] 掉装备 **60%** 会不会太多？（`DROP_CHANCE`；装备会进全局背包，影响第 4 关的武器）
- [ ] 咬人**不掉血**是不是太温柔？（现在是只推人 + 提示按 F，怕小朋友被咬死会哭）
- [ ] 要不要给小怪兽加「打倒后掉钥匙 / 开锁门」的玩法？（这一版没做，见 D-011）
- [ ] 这一关和 `program/ROADMAP.md` 点子池里的「**迷宫里找钥匙**」是同一类玩法，
