## 二、编号规则（2026-10-24 改过）

- 卡号 `L00`…`L99` = **游戏内顺序**（源码里的 `order`），**不是**小朋友口述的编号。
- 小朋友口述里的编号（第一关 / 第三关的第二关 / 第五关…）是**档案**，只写在
  `transcripts/` 和 `levels/_ideas/` 里，**不拿来当卡号**。
  例：小朋友 2026-10-23 说「第五关也是猜谜语」，游戏里谜语森林其实是**第 1 关**。
- 改关卡顺序 = 同时改两处：`src/levels/index.js` 的清单顺序 / `order`，以及本表的卡号。
- 关卡 `id` 定下来**不许改**（存档按 id 分区，改了小朋友的进度就没了）。

## 四、一关一机制（判重）

| 关卡 | 核心机制 | 和别人重复吗 |
|------|----------|--------------|
| L01 谜语森林 | 猜谜（三选一，答错给提示） | 和 L02/L03 共用「答题弹窗」这个**引擎能力**，但玩法不同：这里是「猜」 |
| L02 宝箱山谷 | 探索寻找 + 答题开门 + 锻造升级 | 和 L01 共用答题，但核心是「找 + 炼」 |
| L03 汉字教室 | 学习（认字 + 小测验 + 换一批） | 和 L01/L02 共用答题，目的是「学」不是「过关」 |
| L04 圆形擂台 | 实时战斗（缩圈 + 击退） | 独一份，全游戏唯一需要打人的关卡 |
| L05 沙漠逃亡 | 骑马 + 限时逃离 | 独一份，全游戏唯一有时间压力 + 载具的关卡 |
| L06 踩白大草原 | 地块状态翻转（踩绿变白）+ 限时 + 找门 | 独一份，全游戏唯一「踩地面」当核心动作的关卡（也骑马，但骑马只是加快踩白，不算重复） |
| L07 石头迷宫 | 随机生成的迷宫 + 限时寻路 + 打怪掉装备 | 独一份，全游戏唯一「迷宫寻路」当核心动作的关卡；也是唯一**不能跳跃**的关卡（`noJump`） |
| L08 风扇小屋 | 找零件 → 变小钻进门 → 装配 → **跨关卡跑腿**取电 → 通电 | 独一份：唯一能用**缩小能力**（`shrink`）钻小门的关卡；也是唯一**任务道具要去别的关卡拿**的关卡（充电器在广场工具台） |

> 判断标准：**核心动词不一样就不算重复**（猜 / 找 / 学 / 打 / 逃 / 装）。
> 共用引擎能力（答题弹窗、传送门、粒子）不算重复。
