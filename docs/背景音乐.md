# 背景音乐（BGM）

适用范围：所有关卡的背景音乐。
一句话总览：**每关一首曲子，全部由浏览器现场合成（零素材、零联网、零版权风险），
开始界面和暂停菜单里都能一键开 / 关。**

代码只有两个文件：
`src/engine/music.js`（曲库 + 播放器）· `index.html` 里的一行 `<script>`
（在 `audio.js` 后面，顺序不能乱）。

## 1. 现在有几首曲子（找的都是「配这个场景」的感觉）

曲子都写在 `src/engine/music.js` 的 `TRACKS` 里，**`id` 必须等于关卡 id**，
这样切关卡就会自动换曲子，不用在关卡代码里写任何东西。

| --- | --- | --- | --- | --- | --- | --- |
| `hub-square` | 方块小镇 | 中央广场（出生点） | 100 | 三角波 | pop | 轻快、暖暖的，像早上出门玩 |
| `riddle-forest` | 谜语森林 | 第 1 关 | 88 | 方波 | soft | 有点神秘，探头探脑 |
| `chest-valley` | 宝箱山谷 | 第 2 关 | 112 | 方波 | pop | 蹦蹦跳跳，一路找过去 |
| `hanzi-classroom` | 汉字教室 | 第 3 关 | 76 | 正弦波 | soft | 安静、专心（不催小朋友） |
| `arena-battle` | 圆形擂台 | 第 4 关 | 138 | 方波 | tense | 紧张、热血（鼓最密） |
| `desert-escape` | 沙漠逃亡 | 第 5 关 | 152 | 方波 | exotic | 急促 + 手鼓感，有点异域风 |
| `paint-the-field` | 踩白大草原 | 第 6 关 | 126 | 三角波 | pop | 蹦蹦跳跳、一脚一脚踩过去的脚步感 |

一种鼓点循环，约 10 秒一循环），和现在游戏里的音效（`src/engine/audio.js` 的
`Game.Sfx`）是同一个路子 —— 音效也是现场合成的。

## 2. 为什么不用现成的 mp3

| 原因 | 说明 |
| --- | --- |
| 离线 | 这是「双击 `index.html` 就能玩」的纯静态游戏，多加一个音乐包就多一份「拷给别的小朋友要带什么」的负担 |
| 版权 | 下载来的曲子不敢随便发给别人玩；自己合成的曲子随便用 |
| 一致 | 音效本来就是合成的，音乐沿用同一套路，不用引入解码 / 加载失败 / 格式兼容这些新问题 |
| 好处 | 每首曲子就是几行「简谱字符串」，**想改随时改，改完刷新就听见**，不用等下载、不用重导出 |

> 以后真要用现成的曲子，再单独开一张任务卡讨论（要一起定：版权、体积、要不要联网）——
> 现在**没有**加载 mp3 的代码，别按「放个文件进去就会响」来理解。

## 3. 怎么开 / 关（小朋友和家长都能点）

两处入口，改的是**同一个存档字段**（`settings.music`）：

1. **开始界面** → `🎵 音乐：开 / 关` 按钮（`#musicBtn`）。
2. **暂停菜单（Esc）** → `🎵 背景音乐：开 / 关` 按钮（`#pauseMusicBtn`）。

细节（都是有意做的）：

- **默认是开**。老存档（v2.4.x 及以前）没有这个字段，载入时自动补上 `music: true`
  （见 `save.js` 的迁移分支），小朋友的进度一个都不丢。
- **设置跟着档案走**：换小朋友 / 导入存档，音乐开关会一起切过去。
- **浏览器规矩**：不许在小朋友点任何按钮之前自动出声。
  所以 `Music.play()` 在没 `init()` 之前只「记账」不发声（`Game.Music.current` 已经是那首了），
  等点了「开始冒险」（或从关卡一览点「进去玩」）才真的响。
- **切到别的页签会自动停**（`document.visibilitychange`）：后台标签页的定时器会被浏览器
  掐到 1 秒一次，不停的话音乐会卡成电音。
- **暂停菜单会暂停音乐**（`director.pause()` / `resume()`），继续玩就接着放。
- **关闭后不会再响**：`setEnabled(false)` 顺手把调度器清掉（`_pauseScheduler`），
  不留在后台空转。

## 4. 想改一首曲子 / 加一首新曲子

打开 `src/engine/music.js`，改 `TRACKS` 里的数据就行（**只改数据，不用碰播放器**）：

```js
'desert-escape': {
  name: '沙漠逃亡',
  bpm: 152,                 // 速度：越大越急
  wave: 'square',           // 主旋律音色：square 电子 / triangle 柔和 / sine 更软
  drum: 'exotic',           // 鼓点风格：pop / soft / rock / exotic / tense（见 DRUMS）
  chords: [                 // 4 小节和弦，每小节 3 个音；第一个音自动当贝斯
    ['E3', 'G3', 'B3'], ['F3', 'A3', 'C4'], ['D3', 'F#3', 'A3'], ['E3', 'G#3', 'B3']
  ],
  lead: [                   // 4 小节主旋律：一小节 16 个十六分音符，'.' 是空拍
    'E5 . . G5 . A5 . B5 . A5 . G5 . E5 . .',
    /* ...一小节一行... */
  ]
}
```

规则：

- 音名写法是 `C5` / `F#4` 这种（字母 + 可选的 `#` + 八度数），`. ` 是休止。
- `chords` 和 `lead` 都按「一小节一行」写，**4 小节一循环**；写成别的长度会靠 `%` 绕回去。
- **新关卡加曲子**：在 `TRACKS` 里加一项，key 用关卡 id（和 `src/levels/index.js` 里的一致）。
  没加也不会报错 —— 那一关会放 `default`。
- 想加新的鼓点风格：在 `DRUMS` 里加一行 16 步的字符串
  （`K` 大鼓 / `S` 小鼓 / `h` 踩镲 / `t` 小嗵鼓，`.` 是空）。

## 6. 调试小工具（浏览器控制台）

```js
Game.Music.tracks            // 曲库（看每关配了哪首）
Game.Music.current           // 现在「该」放哪首（不等于正在响）
Game.Music.playing           // 真的在响吗
Game.Music.play('desert-escape')   // 立刻切到某首
Game.Music.setVolume(0.2)    // 音量 0~1（默认 0.35）
Game.Music.setEnabled(false) // 等于点了「音乐：关」
Game.Music.toggle()
```

## 附：和「引擎层」的关系

背景音乐属于**引擎层能力**（`src/engine/`），所以在多 Agent 协作里归 **C2 引擎架构师**：
关卡作者**不用**自己写音乐代码，只要关卡 id 和曲子 id 对上就行；
要改音乐引擎 / 新增对外接口 → 发 CHANGE 卡（见 `AGENTS.md` 第 3.4 节）。
