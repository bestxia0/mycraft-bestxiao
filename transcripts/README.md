# transcripts · 小朋友口述原文

这里是**最高级证据（E0）**：小朋友的原话。

## 规则

1. **只增不改**。要修正，就追加一条新记录并在文末写日期，不编辑历史记录。
2. 逐字保留，包括重复、口误、跳号的关卡编号。
3. 文件命名：`<日期>-<主题>-口述.md`，例：`2026-10-23-传送门关卡-口述.md`。
4. 录音原文件（如 `.m4a`）放在本目录下的 `audio/`，同名同日期；音频不进 git 也没关系，文件名写进对应 md 即可。
5. 本目录里的内容**不得**被 AI 改写、润色或"整理通顺"——整理稿请放 `levels/`（标 [整理]）。

## 没有录音怎么办

先用语音输入法把话听写成文字贴进来，一样有效。
转写命令见 `docs/工作流程.md` 步骤 2。
